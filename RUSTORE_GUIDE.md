# Инструкция по сборке и публикации «Number Match» в RuStore

Данное руководство содержит все необходимые шаги, готовые тексты описаний и команды для выгрузки вашей игры в официальный каталог **RuStore** (Консоль разработчика: [console.rustore.ru](https://console.rustore.ru)).

## 📁 Что уже подготовлено в проекте

1. **Android проект (`/android`)**: настроен через Capacitor (`ru.numbermatch.game`).
2. **Иконка приложения**:
   - `public/icon.png` и `public/icon-512.jpg` — высококачественная иконка 512×512 для загрузки в карточку RuStore.
   - Иконки интегрированы в Android ресурсы (`res/mipmap-*`).
3. **Ориентация экрана**: зафиксирован портретный режим (Portrait) в `AndroidManifest.xml`.
4. **Манифест и PWA метаданные**: добавлены `public/manifest.webmanifest`, favicons и `meta theme-color`.
5. **Политика конфиденциальности**: подготовлен файл `PRIVACY_POLICY.md` (обязателен для прохождения модерации).

## 🛠 Шаг 1. Сборка APK / AAB

Для выгрузки в RuStore принимается файл с расширением **`.apk`** или **`.aab`** (Android App Bundle).

### Вариант А: Через Android Studio (Рекомендуемый и самый простой способ)
1. Скачайте репозиторий проекта на ваш компьютер (через кнопку *Export to ZIP* / *GitHub* в меню настроек AI Studio).
2. Установите бесплатную [Android Studio](https://developer.android.com/studio).
3. В терминале проекта выполните:
   ```bash
   npm install
   npm run build:android
   ```
4. Откройте Android Studio и выберите **Open**, указав папку `android` внутри проекта.
5. Подождите 1–2 минуты, пока Gradle синхронизирует проект.
6. В верхнем меню Android Studio нажмите:
   **Build -> Generate Signed Bundle / APK...**
7. Выберите **APK** (или Android App Bundle).
8. Создайте новый ключ подписи (Keystore):
   - Укажите путь сохранения файла ключа (например, `my-release-key.jks`)
   - Задайте пароль
   - Заполните имя (First and Last Name)
9. Выберите сборку **release** и нажмите **Create**.
10. Готовый подписанный файл `app-release.apk` будет лежать в `android/app/release/`.

### Вариант Б: Сборка через терминал (Gradle)
Если у вас установлен Android SDK:
```bash
cd android
./gradlew assembleRelease
```
Файл APK появится в `android/app/build/outputs/apk/release/`.

## 📝 Шаг 2. Регистрация в Консоли RuStore

1. Перейдите на сайт **[console.rustore.ru](https://console.rustore.ru)**.
2. Авторизуйтесь с помощью **VK ID** или Сбер ID.
3. Выберите тип аккаунта:
   - **Физическое лицо** (достаточно паспорта или быстрой верификации через Госуслуги / Т-Банк / Сбер).
   - **Самозанятый** или **Юридическое лицо / ИП**.
4. Заполните профиль разработчика (имя/название, которое увидят игроки).

---

## 📤 Шаг 3. Создание приложения в RuStore

1. В Консоли нажмите синюю кнопку **«Добавить приложение»**.
2. Загрузите ваш файл **`app-release.apk`** (или `.aab`). Система автоматически распознает:
   - Имя пакета: `ru.numbermatch.game`
   - Версию: `1.0 (1)`

## 📋 Шаг 4. Заполнение данных карточки игры (Готовые тексты)

### 1. Название приложения (до 30 символов)
```text
Number Match: Игра в числа
```

### 2. Краткое описание (до 80 символов)
```text
Увлекательная логическая головоломка с числами: находи пары и очищай поле!
```

### 3. Полное описание (до 4000 символов)
```text
«Number Match: Игра в числа» — легендарная классическая головоломка, знакомая многим с детства как «Семечки», «Числа», «19» или «Цифры»!

Идеальная игра для тренировки внимания, логики и приятного отдыха после рабочего дня.

Правила просты и увлекательны:
• Ваша цель — очистить всё игровое поле от чисел.
• Находите и вычеркивайте пары одинаковых чисел (например, 7 и 7, 3 и 3) или пары, сумма которых равна 10 (например, 1 и 9, 4 и 6, 5 и 5).
• Числа могут стоять рядом по горизонтали, по вертикали, по диагонали, а также через конец одной строки и начало следующей.
• Между числами могут находиться уже вычеркнутые клетки — они не мешают составлению пары!
• Когда ходы закончатся — нажмите кнопку «+ Добавить числа», и все оставшиеся цифры продублируются в конец поля.

Особенности игры:
✓ Классический бесконечный режим для долгих сессий и рекордов.
✓ Режим кампании: 10 увлекательных уровней с особыми заданиями (ограничение ходов, сбор заданных сумм, очистка строк).
✓ Ежедневные головоломки (Daily Challenges): новая уникальная головоломка каждый день!
✓ Полезные бустеры: Умная подсказка, Отмена хода, Перемешивание, Ластик для одиночной цифры и Бомба 3x3.
✓ Разнообразные темы оформления: «Элегантный темный OLED», «Школьная тетрадь в клеточку», «Пастельный закат» и «Изумруд».
✓ Подробная статистика побед, комбо и рекордов.
✓ Полная поддержка игры без интернета (офлайн).

Проверьте свои силы и станьте мастером чисел!
```

### 4. Категория
- **Категория**: `Игры`
- **Подкатегория**: `Головоломки` (или `Настольные` / `Казуальные`)

### 5. Возрастной рейтинг
- Выберите **`0+`** или **`3+`** (игра не содержит насилия, ненормативной лексики или азартных элементов).

### 6. Иконка приложения
- Загрузите подготовленный файл **`public/icon-512.jpg`** (размер 512×512 px, квадрат без скругления углов — RuStore скруглит их автоматически).

### 7. Скриншоты
- Сделайте от 2 до 10 скриншотов с экрана вашего телефона или в браузере (F12 -> режим мобильного экрана iPhone/Pixel).
- Рекомендуемые кадры:
  1. Главный игровой экран с числами и комбо-эффектом.
  2. Выбор уровней или режим ежедневной игры.
  3. Экран победы со звездами и очками.
  4. Меню тем оформления (школьная тетрадка, темная тема).

### 8. Политика конфиденциальности
- Если у вас есть личный сайт или страница на GitHub Pages, разместите текст из `PRIVACY_POLICY.md` и вставьте ссылку.
- Либо укажите ссылку на ваш репозиторий с файлом `PRIVACY_POLICY.md`.

---

## 🚀 Шаг 5. Отправка на модерацию

1. Нажмите **«Отправить на модерацию»**.
2. Проверка приложений в RuStore обычно занимает **от 1 до 24 часов**.
3. После одобрения статус изменится на **«Опубликовано»**, и игра станет доступна миллионам пользователей RuStore!
